# Tasks

## 1. 内容面板置顶

- [x] 1.1 在应用作用域保存置顶状态，在面板作用域接入 NSGo 窗口层级与能力检测。为翻译、问答和历史共用的标题栏添加置顶按钮、选中样式和不可用说明。打开面板，检查按钮位于收起按钮旁，且可用时能通过键盘切换。
- [x] 1.2 用 `nsgotest` 覆盖默认关闭、通过按钮开启和取消置顶、页面间共享状态及不支持时的按钮状态。运行 `go test ./internal/app` 验证该模块。

## 2. 桌面验收

- [x] 2.1 在 Windows 打开一个与面板重叠的普通窗口并切换焦点，确认置顶时面板仍在上方，取消置顶后可被覆盖。再确认 Esc 和收起按钮都可隐藏已置顶面板，通过快捷键和托盘重新唤起时保留状态，退出重启后默认关闭。
- [x] 2.2 在受支持的 Linux X11 会话重复任务 2.1 的桌面验收。
- [x] 2.3 在 Linux Wayland 会话通过可用入口打开面板，检查置顶按钮处于禁用状态、原因可读，且仍可收起面板。

X11 验收使用 Xvfb 与 Openbox，确认置顶及取消后的遮挡顺序、Esc 和按钮收起、热键与托盘唤回以及重启复位。Wayland 验收使用嵌套 Weston，确认置顶按钮禁用、提示可见、托盘可唤回。
