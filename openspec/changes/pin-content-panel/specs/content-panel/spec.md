# Spec Delta

## Purpose

用户可以在阅读或操作其他应用时，把 Go Ask 的翻译、问答或历史会话保留在普通窗口上方，也可以随时恢复普通窗口层级，让其他窗口按惯常顺序覆盖它。

## ADDED Requirements

### Requirement: 切换内容面板置顶

在支持调整内容面板窗口层级的桌面会话中，应用必须（MUST）在公共标题栏提供一个可用鼠标和键盘操作的置顶按钮。按钮须显示当前状态，并提供「置顶」或「取消置顶」的操作名称。

#### Scenario: 开启和关闭置顶

- **WHEN** 用户在未置顶时激活「置顶」按钮
- **THEN** 内容面板保持在当前桌面的普通窗口上方，即使焦点切到其他应用，按钮也显示已置顶并提供「取消置顶」操作
- **WHEN** 用户激活「取消置顶」按钮，再将焦点切到与面板重叠的普通窗口
- **THEN** 该窗口可以覆盖面板，按钮恢复未置顶状态

#### Scenario: 桌面会话不支持调整层级

- **WHEN** 用户在不支持调整内容面板窗口层级的桌面会话中打开内容面板
- **THEN** 置顶按钮显示不可用，并提供「当前桌面不支持置顶」说明

### Requirement: 内容面板置顶状态的生命周期

应用必须（MUST）在本次运行内为翻译、问答和历史会话使用同一个置顶状态，并在每次启动时默认关闭置顶。

#### Scenario: 切换页面

- **WHEN** 用户置顶后切换翻译、问答或历史会话
- **THEN** 面板保持置顶，各页面标题栏均提供「取消置顶」操作

#### Scenario: 收起并重新唤起面板

- **WHEN** 用户置顶后按 Esc 或点击「收起窗口」，再通过快捷键或托盘重新唤起面板
- **THEN** 面板可以正常收起，并在重新唤起后继续置顶

#### Scenario: 重启应用

- **WHEN** 用户在置顶状态下退出 Go Ask 并重新启动，然后打开内容面板
- **THEN** 置顶默认关闭，在支持调整层级的桌面会话中，面板使用普通窗口层级
