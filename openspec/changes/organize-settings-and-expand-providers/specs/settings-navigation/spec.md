# Spec Delta

## Purpose

设置窗口按用途组织快捷键、窗口行为和在线服务。用户可以从左侧直接切换分类，在右侧查看或修改对应设置，并在切换前后继续编辑同一份服务配置。

## ADDED Requirements

### Requirement: 按分类浏览设置

设置窗口必须（MUST）在左侧提供可通过鼠标和键盘切换的「常规」「翻译服务」「AI 提供商」，清楚标识当前选中项，并在右侧显示对应内容。

#### Scenario: 打开和切换分类

- **WHEN** 用户打开设置并切换到「翻译服务」或「AI 提供商」
- **THEN** 左侧标明当前分类，右侧显示该分类的服务与配置操作

#### Scenario: 操作常规设置

- **WHEN** 用户在「常规」修改快捷键、失焦收起或面板空闲释放
- **THEN** 设置按现有生效与持久化行为工作

### Requirement: 切换分类保留服务编辑

设置窗口必须（MUST）在本次打开期间保留各服务尚未保存的编辑，并在用户明确保存后才应用服务变更。

#### Scenario: 往返分类或服务

- **WHEN** 用户编辑服务字段，切换到其他服务或分类后再返回
- **THEN** 可以继续编辑原内容，应用继续使用上次成功保存的配置
