# Spec Delta

## Purpose

内容面板在用户切换到其他窗口后可以自动收起，让原来的工作窗口恢复可见。用户可以保存自己的失焦偏好，或临时置顶面板，在操作另一个窗口时继续查看面板内容。

## ADDED Requirements

### Requirement: 配置主窗口失焦收起

设置窗口必须（MUST）提供「失焦时收起主窗口」开关。没有保存该项设置时默认开启，保存成功后在本次运行生效，并在重启后恢复。

#### Scenario: 首次运行或读取旧设置

- **WHEN** 用户在首次运行时打开设置，或已有配置缺少失焦收起字段
- **THEN** 设置开关显示为开启

#### Scenario: 关闭开关并重启

- **WHEN** 用户关闭开关并看到保存成功，随后重新启动 Go Ask
- **THEN** 开关保持关闭，主窗口失去焦点时仍可见

#### Scenario: 保存失败

- **WHEN** 应用无法保存开关设置
- **THEN** 设置窗口显示失败原因，开关和失焦行为保持最近一次成功保存的状态

### Requirement: 按窗口焦点收起主窗口

当开关开启且主窗口未置顶时，已经获得焦点的主窗口必须（MUST）在失去窗口焦点时收起。自动收起遵循手动收起的唤回、空闲释放和后台任务行为。

#### Scenario: 将焦点切到另一窗口

- **GIVEN** 主窗口可见、未置顶、已获得焦点且开关开启
- **WHEN** 用户切到其他窗口，包括打开独立的 Go Ask 设置窗口
- **THEN** 主窗口收起，目标窗口继续拥有焦点，正在生成的问答继续运行

#### Scenario: 操作面板内部控件

- **WHEN** 用户在主窗口内部切换控件焦点、切换内容页或打开语言选项
- **THEN** 主窗口保持可见

#### Scenario: 置顶时切换窗口

- **WHEN** 用户置顶主窗口后切到其他窗口
- **THEN** 主窗口保持可见。取消置顶后，下一次失焦按当前开关处理

#### Scenario: 唤回因失焦收起的窗口

- **WHEN** 用户通过热键或托盘唤回因失焦收起的主窗口，且唤回成功获得焦点
- **THEN** 主窗口可见并可输入，在下次失焦前保持打开。若此前已超过设置的空闲释放时限，则重建主窗口
